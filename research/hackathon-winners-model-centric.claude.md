# Hackathon winners: model-centric events

- **Question:** What won at hackathons themed on fine-tuning, RL, evals, small models or LLM infrastructure, with what stack and demo format, and how were they judged?
- **Author:** Claude (Claude Code, Opus 5.5)
- **Date:** 2026-10-23

## Summary

- The best-documented model-centric winners are RL **environments** (Nous Research, May 2025): the winning entries pair a task with an automatic reward (game win/loss, likelihood improvement, Jaccard similarity, LLM judge) and ship as code in a shared repo plus W&B runs. (observed: `NousResearch/atropos`)
- Small-model events reward measured efficiency: AI Tinkerers Paris scored SLM-generated Polars code on correctness vs speed and VRAM; winners used RAG, 4-bit quantisation and self-repair loops on ~3B models. [AI Tinkerers](https://paris.aitinkerers.org/hackathons/h_sj1ca_J4Hdk/results)
- "Self-improving agents" is a recurring theme (W&B WeaveHacks 2 and 3, 2025–2026) with RL tracks and serverless-RL sponsor prizes; full winner lists were not found.
- Published judging criteria are usually four equal parts close to Night Shift's: e.g. Mistral (impact, technical implementation, creativity, presentation; ≤ 2 min video). [Mistral](https://mistral.ai/news/2024-ft-hackathon/)
- A public post-mortem shows fine-tuning can fail under hackathon time: an AMD Q&A tournament entrant abandoned four LoRA/distillation attempts (mode collapse) for an untuned Qwen2.5-7B and did not place. (observed: `bledden/AMD_Hackathon`)

## Findings

### Nous Research RL Environments Hackathon (2025-05-18, $50,000 pool)

- Format: build environments in Atropos, Nous's RL environments framework (released April 2025). [Nous on X](https://x.com/NousResearch/status/1922434774620139982), [Atropos](https://nousresearch.com/introducing-atropos) (search summaries)
- Subjective track: 1st Pokemon Trainer (iyajainfinity, AlexReibman); 2nd VR-CLImax (JakeABoggs); 3rd DynastAI (David van Vliet, SRacoon23). Objective track: 1st CyberMaxxing (1999_karthik); 2nd HelpfulDoctors; 3rd Physical RL (nullref0, venkatacrc). [Nous recap](https://x.com/NousResearch/status/1925381154666070172) (search summary)
- Code for entries lives in `environments/community/` of [NousResearch/atropos](https://github.com/NousResearch/atropos) (observed: shallow clone, last commit 2026-07-04):
  - `pokemon-showdown`: LLM player vs a "Max Damage" bot on a local Pokémon Showdown server; reward = binary win/loss at battle end.
  - `punchline_vrcli`: trains punchline generation with VR-CLI (Gurung & Lapata, 2025): reward = how much the model's reasoning lowers perplexity of the dataset's true punchline.
  - `dynastai`: medieval kingdom game with four metrics (power, stability, piety, wealth); scenario cards generated by Qwen 1.7B via OpenRouter; FastAPI backend plus HTML/JS front end; adaptive reward.
  - `cybersecurity_sigma`: generates Sigma detection rules (YAML) from threat-hunting prompts; two rewards, Jaccard token similarity and LLM judge; dataset `mmaisel1/nous-rl-hackathon-sigma`. Its link to the "CyberMaxxing" entry is not confirmed.
  - `helpful_doctors`: MedQA items rewritten with three synthetic patient personas (cooperative, reluctant, neutral) to test diagnosis robustness; README links a W&B project and a YouTube short and notes an accuracy score was not finished in time.
  - `physical_space_stl`: trains LLMs to output STL (CAD) files, rendered for scoring.
- Demo format observed: environment code + README + W&B run + short video.

### AI Tinkerers Paris: "Benchmarking Small Language Models in the Real World" (featuring OSMOZ)

- Challenge: small language models generate Python code using Polars on large datasets; scoring weighs correctness against speed and VRAM. [event page](https://paris.aitinkerers.org/p/hackathon-benchmarking-small-language-models-in-the-real-world) (search summary)
- 1st (final round): Darkwood: RAG plus specialised Polars prompting on a 3B model. Best Startup: bluebull: 4-bit quantisation and a self-repair loop. Finalist: Muon: "Pseudo-RAG" routing and post-processing. Other finalists: Polaris, Training Expert. [results](https://paris.aitinkerers.org/hackathons/h_sj1ca_J4Hdk/results) (search summary)
- Event year: not found.

### W&B WeaveHacks (self-improving agents)

- WeaveHacks 2 (2025-10-12, San Francisco; W&B, Google Cloud, Browserbase, Daytona, AG-UI, Mastra, Tavily): 138 participants, $18,027 prizes; Grand Prize, Best Self-Improving Agent ($2,000), Reinforcement Learning track ($1,000), OpenPipe/W&B serverless-RL sponsor prize; public GitHub repo required. Winners not found. [Devpost](https://weavehacks2.devpost.com/) (search summary)
- WeaveHacks 3: Self-Improving Agents (2026-01-31 to 02-01, W&B SF office): top prize robot dog + $2,000; judges included Dex Horthy (HumanLayer) and Christopher Chedeau (Meta); 61 projects. 4th place: SolverFit Labs, RL to tune an LLM for a specific metric, repo `matthieujules/coreweave-hackathon`. Other placings not found. [Luma](https://luma.com/weavehacks3), [gallery entry](https://cerebralvalley.ai/e/weave-hacks-3-self-improving-agents-hackathon-with-weights-and-biases-7014fe80/hackathon/gallery/23.md) (search summaries)
- WeaveHacks 4 (June 2026): multi-agent orchestration theme; results not found. [Luma](https://luma.com/weavehacks)

### OpenEnv (Meta PyTorch, Hugging Face, Unsloth)

- OpenEnv Hackathon SF (2026-03-07/08, Cerebral Valley and Shack15): $100K+ pool, 10 tracks per Berkeley RDI. Gallery entries include VendEnv (GRPO via Unsloth on Qwen2.5-1.5B) and Signall (Unsloth + GRPO). A Northeastern University post (2026-05-12) reports a team won $10,000; placing not stated. [PyTorch](https://pytorch.org/event/openenv-hackathon-sf/), [Cerebral Valley](https://cerebralvalley.ai/e/openenv-hackathon-sf), [Northeastern](https://siliconvalley.northeastern.edu/category/experiential-learning/hackathons/) (search summaries)
- OpenEnv Challenge (AgentBeats / Hugging Face): $10,000 credits plus a PyTorch.org blog feature; deadline 2026-03-30; criteria: creative use of OpenEnv, technical excellence, storytelling, open-source demo, "green agent" wrapper. [EdTech Innovation Hub](https://www.edtechinnovationhub.com/news/uc-berkeley-agentbeats-competition-backs-hugging-face-agentic-rl-challenge) (search summary)
- Example entry: Memex, an anti-money-laundering investigation environment training Qwen2.5-7B via Unsloth. [razancodes/Meta-Pytorch-Hackathon](https://github.com/razancodes/Meta-Pytorch-Hackathon) (search result; placing unknown)

### Model-vendor hackathons

- Mistral AI fine-tuning hackathon (virtual, 2024-06-05 to 06-30, around its fine-tuning API): €2,500 API credits to each of the top three; judged equally on impact, technical implementation, creativity, presentation; entry = code link, short description, ≤ 2-minute video; teams ≤ 4. Winners not found. [Mistral](https://mistral.ai/news/2024-ft-hackathon/) (search summary)
- Gemma 3n Impact Challenge (Kaggle, 2025; 600+ projects; judged writeups, no leaderboard): 1st Gemma Vision (assistant for visually impaired users; chest-worn phone camera; Gemma 3n via MediaPipe LLM Inference API; also Google AI Edge prize); 2nd Vite Vere Offline (moved from Gemini API to on-device Gemma 3n); 3rd 3VA (fine-tuned Gemma 3n to turn pictograms into rich expressions). [Google blog](https://blog.google/innovation-and-ai/technology/developers-tools/developers-changing-lives-with-gemma-3n/) (search summary)
- Meta Llama Impact Hackathon London (November 2024, with Cerebral Valley): 200+ developers, 56 teams, Llama 3.2; winner Guardian, an A&E triage assistant ("Atlas"); top three shared $50,000 plus six weeks' mentorship. Fine-tuning use not stated. [Meta](https://about.fb.com/news/2024/11/metas-llama-impact-hackathon-pioneering-ai-solutions-for-public-good/) (search summary)

### Post-mortems and contemporary entries (not winners)

- AMD Hackathon Q&A Agent Tournament (deadline 2025-10-29): entrant trained Qwen2.5-72B LoRA specialists, RSLoRA and DoRA variants and 3,000 distillation questions (8.5 h), then shipped untuned Qwen2.5-7B-Instruct (claimed 92% on 50 validation questions); "did not place". (observed: [bledden/AMD_Hackathon](https://github.com/bledden/AMD_Hackathon) README)
- Ratchet, an in-progress entry to the Nebius × NVIDIA Global AI Hackathon (deadline 2026-10-30; four equal criteria: technological implementation, design, potential impact, quality of the idea): an OpenAI-compatible gateway where a Nemotron Nano 4B + LoRA student answers first, a Nemotron 3 Ultra teacher answers when the student is unsure, and nightly LoRA training ships only past a statistical gate with shadow → canary 10/50/100% → rollback. Measured: text-to-SQL adapter 33.1% vs 12.8% base on 172 held-out rows, from 821 teacher-labelled rows costing about $3; dashboard figures are simulation. (observed: [harshbhx/ratchet](https://github.com/harshbhx/ratchet) README and `docs/HACKATHON_SUBMISSION.md`, commit of 2026-10-23)
