# Winning AI application projects

- **Question:** What did publicly documented AI application hackathon winners build, and how were their sponsor integrations and demos described?
- **Author:** gpt (GPT-6)
- **Date:** 2026-10-23

## Summary

- GibberLink's authors report first place at an ElevenLabs × a16z hackathon and provide a two-agent hotel-booking demonstration. [Project](https://github.com/PennyroyalTea/gibberlink)
- VocalAIAgent reports the “Most Ambitious Vapi Project” award at UC Berkeley's 2025 AI hackathon. [Project](https://github.com/ramizik/vocal-ai)
- CrossBeam reports winning Anthropic's 2026-02-10 to 2026-02-16 Claude Code hackathon with an ADU permit application assistant. [Project](https://github.com/mikeOnBreeze/cc-crossbeam)
- These are application projects; no prize or ranking claim below was inferred from stars or a project's presence in an “awesome” list. [GibberLink](https://github.com/PennyroyalTea/gibberlink) · [CrossBeam](https://github.com/mikeOnBreeze/cc-crossbeam)

## Findings

### GibberLink

- **Event/date/placing:** The authors report first place at the ElevenLabs × a16z international hackathon and date the viral demonstration to 2025-02. Exact event days and the geographic scope of the placing were not established from the inspected README. It links a Devpost submission and press reports. [Project](https://github.com/PennyroyalTea/gibberlink)
- **Repository:** [PennyroyalTea/gibberlink](https://github.com/PennyroyalTea/gibberlink).
- **Task and stack:** Two conversational agents act as a hotel caller and receptionist. On recognising the other side as AI, they switch from English to the `ggwave` data-over-sound protocol. [Architecture](https://github.com/PennyroyalTea/gibberlink)
- **Sponsor product:** ElevenLabs conversational AI powers the independent speaking agents; the repository supplies an API for the sound protocol. [Project](https://github.com/PennyroyalTea/gibberlink)
- **Demo format:** Linked recorded video and a browser demonstration intended to run across two devices; neither live service nor video playback was tested here. [Demo links in README](https://github.com/PennyroyalTea/gibberlink)
- **Judging criteria:** Not found in the retrieved repository; the linked Devpost page could not be retrieved because of network restrictions. [Submission link in README](https://github.com/PennyroyalTea/gibberlink)

### VocalAIAgent

- **Event/date/placing:** The README claims “Most Ambitious Vapi Project” at UC Berkeley Hackathon 2025. Exact event days and an overall placing are not supplied. [Project](https://github.com/ramizik/vocal-ai)
- **Repository:** [ramizik/vocal-ai](https://github.com/ramizik/vocal-ai).
- **Task and stack:** Vocal coaching combines pitch/voice analysis, exercise recommendations and progress history. The documented stack includes React/TypeScript/Vite, FastAPI/Python, Supabase, Fetch.ai and Letta. [Stack and features](https://github.com/ramizik/vocal-ai)
- **Sponsor product:** Vapi supplies real-time voice conversations with the AI coach; the repository's award claim names Vapi. It also describes Fetch.ai proactive analysis and a Letta conversational agent. [Project](https://github.com/ramizik/vocal-ai)
- **Demo format:** A YouTube demo and hosted web app are linked; playback and the hosted workflow were not verified here. [Demo references](https://github.com/ramizik/vocal-ai)
- **Judging criteria:** Not found in the retrieved README. [Inspected source](https://github.com/ramizik/vocal-ai)

### CrossBeam

- **Event/date/placing:** The author reports “Winner” of Anthropic's Global Claude Code Hackathon, “Built with Opus 4.6”, held 2026-02-10 to 2026-02-16. It links an announcement from the Claude account; the README does not specify a numbered placing. [Project](https://github.com/mikeOnBreeze/cc-crossbeam)
- **Repository:** [mikeOnBreeze/cc-crossbeam](https://github.com/mikeOnBreeze/cc-crossbeam).
- **Task and stack:** A contractor uploads architectural plans and a city corrections letter; an agent interprets the corrections and produces a response package. Next.js/React, Express/Cloud Run, Vercel Sandbox and Supabase form the documented application stack. [Architecture](https://github.com/mikeOnBreeze/cc-crossbeam)
- **Sponsor product:** Claude Opus 4.6 and the Agent SDK process plans and references; the author says the whole project was built with Claude Code. [Project](https://github.com/mikeOnBreeze/cc-crossbeam)
- **Demo format:** The README describes an upload → research/clarification → generated-package workflow and includes test assets and sample output. The actual judged presentation's duration and whether it was live were not found. [Workflow and project structure](https://github.com/mikeOnBreeze/cc-crossbeam)
- **Judging criteria:** A requirement or scoring rubric was not found in the inspected README; the named model/build tools describe the entry, not a verified rubric. [Inspected source](https://github.com/mikeOnBreeze/cc-crossbeam)

### AgenticCaregivers

- **Event/date/placing:** The README reports “Winner of the Doctolib AI × One Health Hackathon 2025”; exact event days, category and numbered placing are not stated. [Project](https://github.com/Magicred-1/AgenticCaregivers)
- **Repository:** [Magicred-1/AgenticCaregivers](https://github.com/Magicred-1/AgenticCaregivers).
- **Task and stack:** Proactive patient follow-up uses doctor-configured agents, calls, record updates and alerts. The architecture names ElizaOS on Scaleway, Supabase and ElevenLabs. These are prototype descriptions, not evidence of clinical efficacy. [Project](https://github.com/Magicred-1/AgenticCaregivers)
- **Sponsor product:** Scaleway hosts the documented agent runtime and ElevenLabs supplies text-to-speech. Doctolib-specific API use was not found in the README. [Workflow diagram](https://github.com/Magicred-1/AgenticCaregivers)
- **Demo format and judging:** A workflow diagram and alert scenarios are provided; a judged presentation recording, duration and scoring rubric were not found. [Inspected source](https://github.com/Magicred-1/AgenticCaregivers)
